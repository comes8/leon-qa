# Leon QA 资金接口调试：第五阶段

入口仍为“本地数据准备”，网页路由 `/api-automation/data-prep`。选择数据集后，点击“资金接口调试 ↓”，进入同页调试区。复用平台账号、项目权限和独立执行器，不需要打开 Postman。

## 第一次完整练习

1. 启动手工环境，创建资金/现货初值 `1000/0` 的专用数据集。alice、bob 各有两账户，币种 TESTUSD。旧环境已关闭时，需要新建环境和数据集。
2. 调试用户选择 alice；转出 funding、转入 spot，金额 `100`。
3. 填业务请求号 `manual-001`。也可以点“生成新请求号”；提交后页面不会自动换号。
4. 可填写需求编号、用例编号、评审备注，例如 `REQ-FUNDS-001`、`CASE-NORMAL-001`。它们是本条调试记录的文本关联标签，不自动创建平台需求/用例，不表示那些内容已经评审。
5. 点击“发起划转”，核对弹窗中的本机环境、用户、方向、金额及请求号，再提交。结果应为 SUCCEEDED，账户快照为 `900/100`；实际流水一借一贷。
6. 点击“按原请求号查询”。只查询原号，不新建划转。
7. 填预期资金余额 `900`、预期现货余额 `100`、预期状态 SUCCEEDED，点击“执行业务断言”。期望不会根据响应自动改成实际值。
8. 查看 SDK 断言中的预期、实际、规则、对象和结果。断言核对余额、资金守恒、流水重放、原请求对应的业务记录、金额/方向/状态、查询与独立 SQL 一致、HTTP 快照与独立 SQL 一致。
9. 保持同号同载荷再发起划转，应该返回原结果，余额仍为 `900/100`，该请求仍一条业务记录、两条流水。
10. 把预期资金余额改成 `901`，再次断言，应显示 FAIL 与 `90100000000`/`90000000000` 的最小单位差异。再改回900复测；原失败记录继续保留。

业务幂等键按“Go数据集ID + 合成用户 + 业务请求号”隔离。重建后是新数据集；不要把在另一个数据集或另一个用户下复用请求号，理解为对原划转的查询或重试。

## 反向场景与结果语义

- 同号改为101：HTTP409/IDEMPOTENCY_CONFLICT；原资金和结果保持。每次调试操作独立记录，业务请求号仍是原号。
- 以新请求号划转超出余额的合法金额：HTTP200，业务状态 REJECTED/INSUFFICIENT_BALANCE，不应按HTTP200显示为划转成功。核对拒绝时填预期 REJECTED、原余额，SDK要求该请求无资金流水。
- 查询不存在的原号：HTTP404/TRANSFER_NOT_FOUND；保留环境，可修正查询号继续调试。
- 传输或原生命令未取得可信回执：显示 UNKNOWN。保留原业务请求号，先查询，不自动换号或重放；最后快照可能过期。执行器本身重启仍沿用第四阶段规则回收旧环境，不会自动恢复业务状态。

| 显示 | 含义 |
|---|---|
| 排队/执行中/已完成 | 工具操作生命周期 |
| RESPONSE / HTTP_ERROR / UNKNOWN | 被测接口已返回、返回HTTP错误、结果未知 |
| NOT_EVALUATED | 尚未执行显式业务断言；不能算测试通过 |
| PASS / FAIL | SDK对明确预期的业务核对结果；FAIL不影响继续查数据 |

操作记录中的“已完成”只代表拿到了该次回执。划转被拒绝、幂等冲突和断言失败均保存真实结果，不通过伪造执行异常来代替业务判定。

## 证据与历史

“本数据集调试历史”可以选择原记录，查看接口响应、前后独立SQL快照、HTTP事件和完整SDK断言；也可导出本条JSON。导出文件仅包含本机合成数据及关联文本，应先审阅自行填写的评审备注再分享。

每条记录绑定环境、平台数据集、当时的Go数据集ID、代次与源码SHA。数据集重建后可以继续查看旧代证据，不能把旧记录当成新代验证结果。“复用本记录输入”只填表，不直接执行，需重新核对当前代次和预期。

浏览器刷新恢复服务端历史。调试表单中的未提交输入不会跨刷新保存；历史显示当前用户、当前项目最近100次操作中属于选中数据集的调试记录，尚无更早历史分页。历史详情及导出仍受本人的项目权限约束。

## 实现与范围

新增固定动作 `transfer`、`query`、`verify`，复用第四阶段操作表及环境串行锁，无新增数据库表。网页不能传任意URL、SQL、Shell命令或远端凭据。

执行器调用固定Go `qa debug` 命令。私有环境描述保存本机MySQL观察连接信息；Go SDK使用只读一致性事务独立观察账户、业务记录和流水，网页及平台后端不另算一份业务公式。平台只验证回执身份、必要规则、断言预期/实际与结论的一致性。私有SQL连接、用户令牌和管理凭据不会返回浏览器或导出记录。

当前固定模型：同用户 funding↔spot、TESTUSD、八位小数、零手续费，无撮合、冻结或在途账户。单笔划转不超过10000000；预期余额允许至20000000，以覆盖资金与现货初值合并的情况。真实现货撮合、合约、DEX及公司接口仍需要第七阶段按契约适配。

关闭网页不清理手工环境。退出使用时点击“停止所选环境”。统一启动、运行诊断、周期健康和故障恢复见[第六阶段运维手册](README_QA_OPERATIONS.md)。
