# Leon QA 接口场景使用说明

本说明只讲第三批新增的“业务用例 → 接口场景 → 本地执行 → 证据”流程。入口：

<http://127.0.0.1:18170/web3/>

先登录 Leon QA，确认后端和前端正常：

```bash
cd /path/to/leon-qa
./leonqa status
```

## 一、先准备业务用例

进入左侧 **Web3 测试 → 用例与评审**。

1. 选择项目和业务设计。
2. 确认用例已经生成，并且完成“用例评审”。
3. 只选择规则、数据和观察方式已经明确的用例。

接口场景会固定当前的业务用例版本。业务用例更新后，需要重新创建接口适配批次。

## 二、创建接口适配批次

进入 **Web3 测试 → 接口场景**，来源选择 **业务设计适配**，点击 **新建接口适配批次**。

填写：

- 适配批次名称
- 业务设计
- 接口服务
- 测试环境
- 执行范围
- 本次需要适配的业务用例

第一次学习建议使用：

- 执行范围：**本地合成模拟**
- 服务：`Leon QA · 现货本地契约 v2`
- 环境：`Leon QA · 本地现货隔离环境 v2`

点击 **保存适配批次**。这一步只保存版本，不发送接口请求。

## 三、预览并生成接口映射

在适配批次中点击 **预览并生成接口映射**。

预览不会调用模型，先检查：

- 业务用例版本是否正确
- 接口文档是否是目标服务
- 环境是否正确
- 是否使用本地模拟或指定 QA/testnet
- 是否明确了独立数据、金额计算和清理方式

确认无误后，点击 **确认生成接口映射**。生成完成后，查看“业务用例到接口步骤”。

重点检查：

1. `coverage_ids` 是否仍对应原测试点。
2. 是否先创建 session，再使用 `session_id`、`order_id` 等变量。
3. 每个步骤是否同时有 HTTP 状态码和业务字段断言。
4. 金额是否使用独立的十进制预期，例如 `5×10=50`。
5. 是否有数据准备或观察缺口。

如果页面显示阻塞项，不要直接发布，先修订。

## 四、另存接口修订

点击 **另存接口修订**，修改 JSON 后填写修订说明，再点击 **另存适配版本**。

修订会生成新版本，例如 `v2`。原版本、模型候选和失败记录都会保留。修订完成后，要重新检查映射和技术阻塞。

## 五、复核并发布

确认没有阻塞后，点击 **复核并发布可执行场景**。

在弹窗中：

1. 选择要发布的业务用例。
2. 填写接口映射、数据准备和观察范围说明。
3. 勾选 **已核对映射、数据准备、独立预期与观察能力**。
4. 点击 **复核并发布**。

发布只创建固定版本的接口用例集，不会执行接口。页面显示“已发布”不等于测试通过。

## 六、执行接口场景

进入 **Web3 测试 → 执行中心**，执行来源选择 **业务设计场景**。

1. 选择刚发布的接口适配版本。
2. 点击 **确认环境并运行**。
3. 核对服务、环境和隔离数据范围。
4. 勾选 **已确认测试环境与本次隔离数据范围**。
5. 点击 **开始本次接口执行**。

执行按每条用例自己的上下文串行进行：

`数据准备 → 业务动作 → 查询观察 → 清理`

写请求不会自动重试。某一步失败后，同一用例的依赖步骤会显示为“受阻”，其他独立用例仍会继续。

执行中可以点击 **请求停止后续步骤**。已经发出的请求会保留证据，未执行的步骤会明确标记为未执行。

## 七、查看证据和导出

在执行中心的 **当次业务证据** 中展开执行任务，可以查看：

- 请求地址、方法和请求体
- 实际响应
- HTTP 与业务断言
- 变量抽取结果
- 失败原因和受阻步骤

点击 **报告与证据** 可以查看历史执行。点击 **导出适配与证据** 保存完整 JSON，包含业务版本、接口快照、发布版本、所有任务和执行证据。

## 常见状态

| 页面状态 | 含义 |
| --- | --- |
| 任务完成 | 执行器处理结束，不代表所有用例通过 |
| 当次范围通过 | 本次执行有完整证据且选定用例均通过 |
| 存在失败用例 | 执行完成，但业务断言有失败 |
| 执行受阻或中断 | 停止、服务重启、版本变化或门禁阻止继续 |
| 尚无执行证据 | 只生成或发布过，还没有运行 |

本地合成模拟只用于学习和接口流程验收，不能代替真实交易所、生产账务、合约、DEX 或链上环境。接入真实 QA/testnet 前，应重新登记接口契约、测试账号、观察接口、清理规则和允许域名。
